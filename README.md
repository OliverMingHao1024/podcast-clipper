# podcast-clipper

專為**純音訊 Podcast** 設計的剪輯工具：把一集節目的錄音，變成可以直接發布的素材。全程在自己的電腦上執行，音檔不會上傳到任何地方。

## 它做什麼

- **挑出精彩短片段**：本機語音辨識產生逐字稿，再由 AI 找出約 1～3 分鐘、適合單獨分享的完整段落，每段輸出音檔、字幕、直式波形影片（燒入字幕）與貼文用的標題和推薦理由。
- **整集剪輯**：自動找出過長的沉默、「嗯」「呃」等贅詞，以及 AI 判斷的講錯重來、錄音事故、離題段落與口頭剪輯指令（例如「這段不能用」），先列成清單讓你確認，再輸出剪好的整集與對應的字幕。
- **集數介紹文案**：根據逐字稿整理簡介與「本集重點」主題清單，可直接貼到節目說明。
- **給不寫程式的人用**：提供只在本機執行的網頁介面，雙擊啟動檔（Windows 的 `start.bat`、macOS 的 `start.command`）就能操作。

AI 部分透過你電腦上已登入的 Claude 命令列工具完成（使用訂閱帳號，不需要 API key）。選段概念參考開源專案 AutoClip，授權聲明見 [NOTICE.md](NOTICE.md)。
